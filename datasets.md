# Project Datasets

## 1. Customer Service SQL EDA

Dataset: Customer Support Ticket Dataset  
Source: https://www.kaggle.com/datasets/suraj520/customer-support-ticket-dataset

Purpose:
Used for SQL EDA, customer service KPI analysis, backlog analysis, ticket priority analysis and resolution time analysis.

## 2. Python Customer Behavior EDA

Dataset: UCI Online Retail Dataset  
Source: https://archive.ics.uci.edu/ml/datasets/Online+Retail

Purpose:
Used for Python EDA, Pandas practice, customer behavior analysis, revenue trend analysis and customer segmentation.

## 3. Retail Sales & Margin Power BI Dashboard

Dataset: Retail Sales Dataset  
Source: https://www.kaggle.com/datasets/buharishehu/retail-sales-dataset

Purpose:
Used for Power BI dashboard, Power Query, DAX, data modeling, sales, profit and margin analysis.

## 4. Regression + Power BI Prediction Dashboard

Option 1: Customer Support Ticket Dataset  
Source: https://www.kaggle.com/datasets/suraj520/customer-support-ticket-dataset

Prediction Target:
Ticket resolution time

Option 2: Food Delivery Time Prediction Dataset  
Source: https://www.kaggle.com/datasets/tipsofficial/food-delivery-prediction

Prediction Target:
Delivery time

## 5. Power BI Report Server Mini Project

Dataset: Microsoft Power BI Sample Datasets  
Source: https://learn.microsoft.com/en-us/power-bi/create-reports/sample-datasets

Purpose:
Used for Power BI report prototyping and Report Server documentation.
