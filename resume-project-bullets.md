# Resume Project Bullets

- Analyzed customer support ticket data using SQL to identify backlog, priority trends and resolution time patterns.
- Created SQL queries for data quality checks, KPI extraction and advanced analysis using CTEs and window functions.

## Python Customer Behavior EDA

- Cleaned and analyzed online retail transaction data using Pandas and NumPy.
- Created visualizations in Matplotlib to identify customer value, product trends and revenue patterns.

## Retail Sales & Margin Dashboard

- Built an interactive Power BI dashboard to analyze sales, gross profit, margin and discount impact.

## Regression + Power BI Dashboard

- Built a regression model in Python to predict business outcomes and evaluated performance using MAE, RMSE and R².
- Exported predictions and created a Power BI dashboard to compare actual vs predicted values.
